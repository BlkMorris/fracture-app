# FRACTURE — Multi-Direction Design Exploration Prompt for AI Agent

## Context Recap

You've already built one Fracture mockup. Now, we want to explore **2-3 completely different visual directions** while staying true to the core strategy:

**Core Strategy (Non-negotiable):**
- Fracture is a media trust platform showing how outlets diverge in framing
- Light theme primary with dark mode option
- Magazine-like aesthetic (generous whitespace, elegant typography)
- Divergence visualization is the hero feature
- No dashboard feel, no opinion, no clutter
- Community-driven (comments build trust)

**What CAN vary:**
- Color palettes (different accent colors, different base tones)
- Typography choices (serif vs. sans approaches, different font pairings)
- Layout strategies (grid variations, card treatments, spacing patterns)
- Component design (how FDI badges look, how divergence is visualized)
- Visual hierarchy (emphasis points, visual weight distribution)

---

## Your Creative Challenge

Design **2-3 fundamentally different visual directions** for Fracture. Each should feel like a distinct interpretation of the same strategic mission.

### Direction Characteristics

**Direction A — Explore Something Bold**
- Consider: A completely different accent color (not blue)
- Consider: A different typography hierarchy approach
- Consider: A unique take on the divergence visualization
- Should feel: Modern, distinctive, pushes boundaries while staying editorial

**Direction B — Explore Something Classic**
- Consider: A more traditional/timeless aesthetic
- Consider: Different serif/sans-serif pairing
- Consider: A more conservative color approach (maybe neutral base with minimal accent)
- Should feel: Authoritative, established, like a publication you trust

**Direction C (Optional) — Explore Something Unexpected**
- Consider: A bold structural or layout choice
- Consider: Unconventional component designs
- Consider: A different visual storytelling approach
- Should feel: Fresh, but not gimmicky; credible but surprising

---

## Requirements for Each Direction

### Visual Specification Per Direction

For each direction, you should independently choose:

**Color Palette:**
- Base/background colors (light mode + dark mode)
- Primary accent color
- Secondary accent (optional)
- Text colors
- Border/divider colors
- FDI color coding (high/medium/low divergence)
- Ensure WCAG AA contrast ratio compliance

**Typography:**
- Headline font (serif/sans/hybrid)
- Body font (serif/sans/hybrid)
- UI font (for buttons, labels, etc.)
- Font sizes and scales
- Line heights and letter spacing

**Layout & Spacing:**
- Grid structure (12 col? 8 col? Different on each?)
- Spacing scale (still 8px base? Or different?)
- Card treatments (how story cards look, padding, borders)
- Max-width containers

**Component Treatments:**
- How FDI badges appear (bars? Meters? Numbers? Custom visualization?)
- How divergence is visualized on story page (spectrum? Scatter? Network? Your idea?)
- How navigation looks
- Button/CTA styling
- Comment section styling

### Pages to Build for Each Direction

Create mockups showing:
1. **Homepage** (story grid, cards, filters)
2. **Story Detail Page** (divergence visualization as centerpiece)
3. **Optional:** Sources Guide OR Search Results (pick one, or build both if inspired)

Each page should demonstrate how the direction's visual language works at scale.

## Naming Your Directions

Give each direction a memorable name/theme that captures its essence:

Examples (don't use these—come up with your own):
- "Editorial Precision" (classic, refined)
- "Modern Minimal" (contemporary, bold)
- "Warm Authority" (accessible, trustworthy)

This makes it easier to reference ("I like the color palette from Direction B but the layout from Direction A").

---

## Design Constraints Per Direction

**All three directions MUST:**
- ✅ Feel magazine-like (not dashboard-y)
- ✅ Make the divergence visualization a focal point
- ✅ Work in both light AND dark modes
- ✅ Have cohesive story cards as atomic units
- ✅ Include FDI badges that are visually interesting
- ✅ Be responsive (or explain mobile approach)
- ✅ Respect the core strategic mission

**Each direction CAN:**
- ❓ Use completely different colors
- ❓ Use completely different typography pairings
- ❓ Arrange layouts differently
- ❓ Treat components uniquely
- ❓ Emphasize different visual elements

---

## Success Metrics

Each direction should be evaluatable on:

1. **Strategic Alignment:** Does it serve the mission? (media trust platform)
2. **Visual Coherence:** Does the color/type/layout system work together?
3. **Distinctiveness:** Could you pick one direction as clearly different from the others?
4. **Magazine Feel:** Does it feel editorial, not analytical?
5. **Divergence Hero:** Is the divergence visualization compelling?
6. **Readability:** Is text readable and hierarchy clear?
7. **Dark Mode:** Does dark mode work seamlessly?

```
PAGES INCLUDED:

- [Optional page]

[Interactive mockups below]
```

This makes it easy to compare across directions and reference them later.

---

## Creative Freedom

**You should feel empowered to:**
- Try accent colors you haven't seen in news products (orange? teal? burgundy?)
- Combine serif/sans in unexpected ways
- Redesign component treatments from scratch
- Propose different information hierarchy approaches
- Challenge the "magazine aesthetic" within reason (but keep it editorial)

**You should NOT:**
- Abandon the light-theme-first approach
- Make it feel like a dashboard/analytics tool
- Add Fracture's opinion to stories
- Make components cluttered or hard to parse
- Forget about dark mode

---

## The Goal

After you deliver these directions, Blake should be able to:
1. See three genuinely different visual interpretations
2. Pick elements from across directions (color from A, type from B, layout from C)
3. Have a clear sense of which direction resonates
4. Use that direction as the foundation for page-by-page refinement

---

## Questions to Guide Your Exploration

As you design each direction, ask yourself:

- What if Fracture's accent color was [X instead of blue]? How would that change the feel?
- What if headlines were sans-serif instead of serif? Would it feel more modern or less editorial?
- What if we used more bold/daring layouts vs. traditional grid? Does it still feel trustworthy?
- What if the FDI badge was [completely different treatment]? Does it still communicate divergence clearly?
- What if dark mode was [different approach—less gray, more color, different contrast]? Does it work?

---

## Final Note

These aren't competing designs where one will "win." They're exploration directions to help Blake understand the visual possibilities and make an informed choice about what direction to take forward.

**Build with creativity, but build strategically. Every color and font choice should have a reason.**
