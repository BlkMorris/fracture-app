# FRACTURE — Page-by-Page Refinement Prompts

Use these quick prompts after you've selected a design direction to iterate on individual pages without rebuilding the entire design.

**How to use:**
1. Pick a page to refine
2. Copy the relevant prompt template below
3. Customize [BRACKETS] with your specific requests
4. Paste to your agent
5. Get updated mockup for that page only

---

## USAGE WORKFLOW

**Recommended refinement sequence:**

1. **First:** Refine the **Homepage** (gets the core visual system right)
2. **Second:** Refine the **Story Detail** (hero page, gets divergence visualization perfect)
3. **Third:** Refine the **Sources Guide** (trust/transparency page)
4. **Fourth:** Polish **navigation and transitions** (consistency across all pages)
5. **Fifth:** Do a **full dark mode** refresh (make sure everything works in both modes)
6. **Finally:** Page-specific polish (FDI badges, comments, filters, etc.)

---

## TIPS FOR EFFECTIVE PROMPTING

- **Be specific:** "Make FDI badges more prominent" is vague. "Make FDI badges 40px tall and add a subtle background color" is clear.
- **Reference context:** If you're changing something, explain why ("The current approach feels too dense, I want more whitespace.")
- **One change at a time:** Easier for the agent to iterate, easier for you to evaluate.
- **Ask for context:** If you say "Return the homepage mockup," the agent returns the whole page. If you say "Return only the story card styling," it knows to zoom in.
- **Be visual:** If possible, describe what you want in visual terms ("the cards should feel more like magazine spreads" vs. "make the cards different").
